Français

Développeur : Yatokishi. Contact pour toute question de confidentialité : yapsonstudio@gmail.com.

NomadIDE est un éditeur de code embarqué (MicroPython, C/C++) pour Android qui permet d'écrire un programme, de le transférer ou de le flasher sur une carte (ESP32, Raspberry Pi Pico, etc.) branchée en USB. Cette politique s'applique à l'application Android NomadIDE (identifiant dev.nomadide.app). Le code source est public : github.com/LeYapson/NomadIDE.

En résumé

  • Aucun compte, aucune inscription.
  • Le développeur ne collecte, ne reçoit et ne stocke aucune donnée personnelle : pas de statistiques d'usage, pas de rapport de plantage, pas de publicité, pas de pistage.
  • Vos projets et réglages restent sur votre appareil.
  • L'application accède à Internet uniquement pour les fonctions décrites ci-dessous, et seulement vers les services indiqués.
  • Aucune donnée n'est vendue ni utilisée à des fins publicitaires.

Données stockées sur votre appareil

Ces données ne quittent pas l'appareil, sauf action de votre part décrite plus bas :

  • vos projets, fichiers et brouillons de code ;
  • vos réglages (langue, préférences d'affichage, mise à jour automatique) ;
  • si vous configurez la compilation à distance : l'adresse du serveur et le jeton d'accès que vous avez saisis ;
  • un cache de bibliothèques MicroPython et de firmwares téléchargés.

Tout est supprimé en désinstallant l'application ou en effaçant son stockage depuis les réglages Android.

Journal de diagnostic

Dans Réglages → Aide, vous pouvez exporter un journal de diagnostic pour signaler un problème. Il est généré seulement à votre demande, copié dans le presse-papiers et enregistré sur l'appareil ; il n'est jamais envoyé automatiquement. Il contient la version de l'application, le système, vos réglages, les cartes USB détectées et les derniers messages d'état et d'erreur, sans le code de vos projets ni les échanges avec la carte. Vous décidez si vous le partagez, et avec qui.

Connexion USB à votre carte

Quand vous branchez une carte, Android vous demande l'autorisation d'accès USB pour NomadIDE. L'application échange alors avec la carte (envoi du code, lecture des fichiers et de la sortie série, flashage de firmware). Ces échanges se font uniquement entre votre appareil et votre carte ; rien n'est envoyé sur Internet.

Accès à Internet : quand et vers qui

L'application demande la seule permission Android INTERNET. Elle ne demande ni localisation, ni contacts, ni appareil photo, ni micro, ni accès aux photos ou fichiers du téléphone en dehors de ses propres dossiers et des fichiers que vous choisissez vous-même.

À propos de la compilation à distance

NomadIDE n'est livrée avec aucun serveur de compilation par défaut et ne vous en impose aucun. Cette fonction est inactive tant que vous n'avez pas renseigné une adresse et un jeton. Le serveur est alors choisi, et le plus souvent exploité, par vous ou par la personne qui vous a fourni l'accès : la façon dont il traite votre code relève de son exploitant. Le service de référence fourni dans le dépôt compile dans un conteneur isolé sans accès réseau, supprime le code source dès la fin de la compilation et efface les binaires générés après 30 minutes. N'envoyez pas de secrets (mots de passe, clés) dans le code compilé à distance.

Services tiers

Les services listés ci-dessus (GitHub, micropython.org, et le serveur de compilation que vous choisissez éventuellement) reçoivent, comme tout site web contacté, votre adresse IP et les informations techniques d'une requête HTTPS. Leur traitement est régi par leurs propres politiques de confidentialité. NomadIDE ne leur transmet ni votre nom, ni un identifiant de l'appareil, ni de donnée de publicité. Toutes les connexions de l'application utilisent HTTPS (HTTP n'est accepté que vers un serveur de votre réseau local).

Partage, vente, publicité

Le développeur ne reçoit aucune donnée utilisateur et n'en partage donc avec personne. Aucune donnée n'est vendue. L'application ne contient aucune publicité, aucun outil d'analyse et aucun SDK de pistage.

Enfants

NomadIDE s'adresse aux personnes de 13 ans et plus (étudiants, curieux, makers) et n'est pas conçue pour les enfants de moins de 13 ans, dont elle ne collecte sciemment aucune donnée. Le développeur ne collecte aucune donnée, quel que soit l'âge de l'utilisateur.

English

Developer: Yatokishi. Contact for any privacy question: yapsonstudio@gmail.com.

NomadIDE is an embedded code editor (MicroPython, C/C++) for Android. You write a program and transfer or flash it to a board (ESP32, Raspberry Pi Pico, etc.) connected over USB. This policy applies to the NomadIDE Android app (package dev.nomadide.app). The source code is public: github.com/LeYapson/NomadIDE.

Summary

  • No account, no sign-up.
  • The developer does not collect, receive or store any personal data: no usage analytics, no crash reports, no ads, no tracking.
  • Your projects and settings stay on your device.
  • The app connects to the Internet only for the features described below, and only to the services listed.
  • No data is sold or used for advertising.

Data stored on your device

This data does not leave the device unless you take an action described below:

  • your projects, files and code drafts;
  • your settings (language, display preferences, automatic update check);
  • if you set up remote compilation: the server address and access token you entered;
  • a cache of downloaded MicroPython libraries and firmware files.

Everything is removed when you uninstall the app or clear its storage in Android settings.

Diagnostic log

In Settings → Help you can export a diagnostic log to report a problem. It is generated only when you ask for it, copied to the clipboard and saved on the device; it is never sent automatically. It contains the app version, the system, your settings, the detected USB boards and the latest status and error messages, without your project code or the exchanges with the board. You decide whether to share it, and with whom.

USB connection to your board

When you plug in a board, Android asks for USB access permission for NomadIDE. The app then talks to the board (sending code, reading files and serial output, flashing firmware). This exchange happens only between your device and your board; nothing is sent over the Internet.

Internet access: when and to whom

The app requests only the Android INTERNET permission. It does not request location, contacts, camera, microphone, or access to your photos or files beyond its own folders and the files you pick yourself.

The desktop versions (Windows, macOS, Linux) can also build on the machine: they then download their tools from GitHub, downloads.arduino.cc and espressif.github.io, only when you install them. This feature does not exist in the Android app.

About remote compilation

NomadIDE ships with no default compile server and does not require one. The feature stays inactive until you enter an address and a token. The server is then chosen, and usually operated, by you or whoever gave you access: how it handles your code is up to its operator. The reference service in the repository compiles inside an isolated container with no network access, deletes the source code as soon as the build ends and erases the generated binaries after 30 minutes. Do not include secrets (passwords, keys) in code compiled remotely.

Third parties

The services listed above (GitHub, micropython.org, and any compile server you choose) receive, like any website you contact, your IP address and the technical information of an HTTPS request. Their handling of it is governed by their own privacy policies. NomadIDE sends them no name, no device identifier and no advertising data. All connections use HTTPS (HTTP is accepted only for a server on your local network).

Sharing, selling, advertising

The developer receives no user data and therefore shares none. No data is sold. The app contains no ads, no analytics tools and no tracking SDKs.

Children

NomadIDE is intended for people aged 13 and over (students, curious users, makers) and is not designed for children under 13, whose data it does not knowingly collect. The developer collects no data, whatever the age of the user.
