Everything you need, in one place

One tool to write a program, try it on the board and install it for good.

  • Serial monitor

    See what your board prints, send it commands, drive DTR/RTS and restart it. Boards are detected as soon as you plug them in.

  • MicroPython

    Interactive console, board files sent and verified, run a file or a selection, and micropython-lib libraries installed in one tap.

  • Code editor

    Python, C and C++ with highlighting, autocomplete, tabs and drafts saved automatically. On a phone, a symbol bar sits above the keyboard.

  • C/C++ and Arduino libraries

    Arduino projects for ESP32 and RP2040, built on your computer or on a server you choose, with Arduino's library catalogue and the versions pinned in the project.

  • Verified flashing

    .uf2 files for RP2040 boards, .bin for ESP32 (even several at once), a check after writing, and the official MicroPython firmware downloaded from the app.

  • For everyone

    French and English interface, light or dark theme, a tutorial on first launch, screen reader support and text enlarged up to 200%.

From idea to board in three steps

The same path as the Flash tab of the app.

  1. Plug in

    A USB cable on a computer, an OTG adapter on a phone. Android asks for permission once.

  2. Write

    Type your program, or build an Arduino project. Try it right away in the console.

  3. Flash

    One button installs the program on the board, checks the write and restarts it.

Respectful, and accessible

Your data stays with you

  • No account, no ads, no tracking tools.
  • The developer receives no data.
  • The Internet is used only to look for an update (can be turned off), download what you ask for, or reach the compile server you configured.

Designed to be usable by everyone

  • Screen reader support (TalkBack on Android).
  • Touch targets of at least 48 dp.
  • WCAG 2.2 AA contrast, checked by automated tests.
  • Text enlarged up to 200% with nothing overflowing.
